Trial admission now reserves declared task memory against Docker MemTotal and releases the reservation when Harbor ends the trial. Host breach checks no longer use live available memory, and the retired spare-memory job limit is rejected with reservation guidance. A new `host_headroom` launch check requires host RAM minus Docker memory to meet `host_reserve_mb` (default 12288), `memory_fits` now needs only the largest task plus the reserve to fit, and machine checks record host RAM.
