# Test shards

The `harbor_contract` shard pins Harbor 0.23.0 behavior with real Harbor job runs and Harbor model objects. It covers local and Git task resolution, empty task filters, Git download-map identity and path, local and Git lock digests, setup and agent-phase interruption layouts, existing agent and verifier failures, resume folder behavior, and viewer job and set-aside layout. Registry datasets remain untested because Harbor resolves them through its registry network service.
